- 2026-08-01: Automated bug-hunt round 7: retrying, re-downloading, or restoring a ready model after a cancelled/failed attempt no longer resets its AddedAt (registry.Put's Model literals now carry the prior record's AddedAt forward, so GET /v1/models' `created` field stays the true first-download time instead of drifting to the retry moment); gitignored build/icon-1024.png, which the Makefile's own comment already claimed was excluded but no rule ever covered, mirroring client/.gitignore's equivalent entry; refuted a control-plane MaxBytesReader gap as a repeat of the round-5 refutation (every loopback caller is by design the full administrator).
- 2026-08-02: Automated bug-hunt round 8: the gateway no longer relays a model-launch failure's raw error to the network — Launcher.Launch failures (which can embed absolute local paths: the venv interpreter, the model directory, a log file) now wrap a new runtime.LaunchError that the gateway matches on to log server-side and answer with a generic message, while other pool errors (memory budget, busy) still reach the client verbatim; evictForLocked no longer picks a still-loading model as an eviction victim (a caller giving up mid-load was dropping inFlight to 0 while the load kept running, and the missing isReady guard — present on reapIdle but not here — could livelock the pool under memory pressure with short client timeouts); the no-absolute-paths-in-docs pre-commit hook now filters matches individually instead of whole lines, so a private path sharing a line with the exempted /Users/Shared/ path is no longer silently waved through. Refuted: a docs tense nitpick ("Clients now send it:" read as ordinary procedural sequencing, not change-narration), a discovery.Stop goroutine-join asymmetry (no reachable shared-state race, single call site, no restart path), and (split verdict) ExposedToLAN's case-sensitive "localhost" check (real but self-inflicted and fail-safe, only reachable by hand-editing config.json).
- 2026-08-02: Automated bug-hunt round 9: Registry.Rescan no longer drops a model from the index on a non-ENOENT stat error (a permission hiccup or transient I/O error on its directory was being treated as proof of deletion, contradicting the code's own "distinguish gone from incomplete" intent; only a confirmed fs.ErrNotExist now counts as gone); Pool.startLocked now calls a new Launcher.Precheck before evicting a resident victim to make room, so a launch failure that strikes moments later (a missing venv, or the new model's own directory vanishing in a race with a concurrent delete) no longer destroys an unrelated, healthy model for zero benefit — eviction is not reversible; /api/search's limit query parameter is now capped, closing an unbounded outbound-request amplification lever reachable even from a blind, Origin-less cross-origin GET. Refuted: handleUnload's uniform 409 for a not-loaded model (repeat of round 5's explicit refutation — ErrNotLoaded reflects pool residency, not registry existence, so 409 is correct and 404 would conflate the two) and a README pitch-text wording difference from the internal IDENTITY.md reference (the file's own practice treats only the one-line tagline as verbatim-shared; the longer pitch is deliberately paraphrased per surface, predates IDENTITY.md, and was never in sync with it).
