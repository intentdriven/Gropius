- 2026-07-30: Automated bug-hunt round 5: stopped Rescan resurrecting failed downloads as ready (completeness now also requires a plausible model config.json and every shard named by model.safetensors.index.json, closing both the missing-shard and junk-config triggers while keeping shared-cache adoption), hardened after security review to refuse non-regular manifest files so a FIFO planted in the shared cache cannot wedge startup; corrected the stale "reachable on the LAN" rationale on redactConfig; respelled the last British code-side stragglers US; deferred the release workflow's rc-tag latest-capture as iss-9 (versioning-policy decision); refuted, among others, the APFS case-collision dedup hazard and a minisign.key gitignore gap (noted for the maintainer as belt-and-braces hygiene).
- 2026-07-30: Automated bug-hunt round 6: completion responses no longer echo the backend's absolute --model path (the gateway maps the model field back to the requested name, JSON and SSE alike); app-created data directories under a setgid shared root are now group-writable setgid so a later account's downloads stop failing (bin deliberately stays closed — it holds executables); client README and install.sh now say to drop the /v1 suffix shown by the Connect tab (GropiusChat adds the path itself); troubleshooting documents the sleeping-Mac failure; archtest scans every internal package (internal/ui was outside the closure); two stale hub comments corrected; deferred shared-root single-writer state files as iss-10 and added a shutdown-liveness design input to iss-5; refuted, among others, stale-weights-after-redownload, dying-predecessor client-mode stranding, and weights-manifest hardening parity.
- 2026-08-01: Automated bug-hunt round 7: retrying, re-downloading, or restoring a ready model after a cancelled/failed attempt no longer resets its AddedAt (registry.Put's Model literals now carry the prior record's AddedAt forward, so GET /v1/models' `created` field stays the true first-download time instead of drifting to the retry moment); gitignored build/icon-1024.png, which the Makefile's own comment already claimed was excluded but no rule ever covered, mirroring client/.gitignore's equivalent entry; refuted a control-plane MaxBytesReader gap as a repeat of the round-5 refutation (every loopback caller is by design the full administrator).
- 2026-08-02: Automated bug-hunt round 8: the gateway no longer relays a model-launch failure's raw error to the network — Launcher.Launch failures (which can embed absolute local paths: the venv interpreter, the model directory, a log file) now wrap a new runtime.LaunchError that the gateway matches on to log server-side and answer with a generic message, while other pool errors (memory budget, busy) still reach the client verbatim; evictForLocked no longer picks a still-loading model as an eviction victim (a caller giving up mid-load was dropping inFlight to 0 while the load kept running, and the missing isReady guard — present on reapIdle but not here — could livelock the pool under memory pressure with short client timeouts); the no-absolute-paths-in-docs pre-commit hook now filters matches individually instead of whole lines, so a private path sharing a line with the exempted /Users/Shared/ path is no longer silently waved through. Refuted: a docs tense nitpick ("Clients now send it:" read as ordinary procedural sequencing, not change-narration), a discovery.Stop goroutine-join asymmetry (no reachable shared-state race, single call site, no restart path), and (split verdict) ExposedToLAN's case-sensitive "localhost" check (real but self-inflicted and fail-safe, only reachable by hand-editing config.json).
- 2026-08-02: Automated bug-hunt round 9: Registry.Rescan no longer drops a model from the index on a non-ENOENT stat error (a permission hiccup or transient I/O error on its directory was being treated as proof of deletion, contradicting the code's own "distinguish gone from incomplete" intent; only a confirmed fs.ErrNotExist now counts as gone); Pool.startLocked now calls a new Launcher.Precheck before evicting a resident victim to make room, so a launch failure that strikes moments later (a missing venv, or the new model's own directory vanishing in a race with a concurrent delete) no longer destroys an unrelated, healthy model for zero benefit — eviction is not reversible; /api/search's limit query parameter is now capped, closing an unbounded outbound-request amplification lever reachable even from a blind, Origin-less cross-origin GET. Refuted: handleUnload's uniform 409 for a not-loaded model (repeat of round 5's explicit refutation — ErrNotLoaded reflects pool residency, not registry existence, so 409 is correct and 404 would conflate the two) and a README pitch-text wording difference from the internal IDENTITY.md reference (the file's own practice treats only the one-line tagline as verbatim-shared; the longer pitch is deliberately paraphrased per surface, predates IDENTITY.md, and was never in sync with it).
- 2026-08-03: Automated bug-hunt round 10: the gateway's non-streaming completion relay no longer buffers an unbounded upstream response (max_tokens/logprobs are client-controlled and unbounded, so a well-behaved mlx_lm.server could still be driven to a very large single JSON object; a new maxResponseBody cap on relayRewritingModel's json branch mirrors the existing maxRequestBody cap on the request side); hub.apiError now reads the captured error body with io.ReadAll(io.LimitReader(...)) instead of a single Read call, which per the io.Reader contract could truncate the message well before its intended 512-byte budget on a body delivered across several small reads. Deferred to the ledger rather than auto-patched: a misleading "Server running in another account" client-mode menu string that, per iss-5's own analysis, can only currently mean a same-account relaunch (noted on iss-5, to be resolved alongside its redesign rather than reworded twice); a genuine data race in the vendored brutella/dnssd library between Advertiser.refresh's UpdateText and the running mDNS responder, confirmed by reading the library source directly, whose only in-repo fix trades an in-place TXT update for a full withdraw/reannounce cycle (new iss-12); and go.mod's module path (github.com/intentdriven/Gropius) not matching the repository's actual location (REPPL/Gropius), latent today but requiring a large mechanical import-path rename across 19 files to fix properly (new iss-13). Refuted: a hub downloadFile size-cap gap (split verdict — technically accurate but not a distinct risk beyond the already-accepted unbounded-download-size design, discarded per the round's split-verdict convention) and a runtime pidLedger EPERM/ESRCH-conflation claim (unreachable — the ledger file's 0600 mode and the shared root's sticky bit block a peer account from ever reading or deleting another account's entries first, the same mechanism iss-10 already documents for registry.json/config.json).
- 2026-08-05: Automated bug-hunt round 12: the archtest GUI-toolkit scan now enumerates internal packages with a wildcard instead of a hand-kept root list that had drifted (internal/mlxtest was entirely unscanned — a planted systray import passed the old test — and internal/capability was covered only through one transitive import); advertised mDNS names are clamped to the 63-octet DNS label limit (macOS permits 63-character LocalHostNames, dnssd validates characters but not length, and its transport silently drops messages that fail to pack, so a 54-plus-character name killed advertising while every layer logged success); distinct repo ids can no longer share a model log file (flattening the slash to an underscore collided a/b_c with a_b/c, and Launch's O_TRUNC then truncated the first model's live log; HuggingFace forbids underscores in namespaces, so the collision is reachable only via sideloaded directories); the getting-started install step now flags its firewall password prompt as the shared-install step already did; a hostname example respelled to the Alice persona. Refuted: a per-line SSE buffering cap for the gateway (the pinned backend emits bounded lines; only the already-tracked local port-squatting class could exceed them), the client README's universal-build claim (true under the README's own SDK requirement, and the release workflow gates on lipo -archs), and the control panel's "bound to loopback only" wording (the user-level guarantee is exact, test-enforced, and stronger than a socket bind would be).
- 2026-08-05: Automated bug-hunt round 13: the gateway's loopback exemption from the API key now also requires a loopback Origin when one is present and a key is configured, closing a CSRF-class bypass — a webpage the user's browser visits also connects from 127.0.0.1, so a no-preflight cross-origin POST (a CORS-safelisted Content-Type needs no Authorization header) rode the exemption straight through /v1/chat/completions even with a key configured, the same class of attack the control plane's loopbackOnly already blocked; the check is gated on apiKey != "" (a merge-gate correctness review caught the first version applying it unconditionally, which narrowed the intentionally open no-key default's loopback behaviour — with no key configured there is no CSRF-defeated key to protect, so that mode is now provably untouched, pinned by a new test). Registry.Remove now broadcasts its in-memory deletion unconditionally, like every other mutator in the file, instead of skipping the notification on a saveLocked or os.RemoveAll failure (the only production subscriber already re-polls live state every 2s, so this was undetectable in the UI, but the code asymmetry was real). AGENTS.md's single-test example now names one real test instead of a `-run TestDownload` pattern that actually matches all 19 tests in internal/hub whose name starts with TestDownload. Refuted: an unbounded control-plane POST body (split verdict — a repeat of the round-5/7 refutation, every loopback caller is by design the full administrator), a per-line SSE buffering cap for the gateway (repeat of round 12's refutation), and a capability/pool RAM-budget fallback divergence on a `sysctl -n hw.memsize` failure (real but inert — the divergence only affects search-result visibility, never actual memory admission, and the trigger has no known path on stock macOS).
